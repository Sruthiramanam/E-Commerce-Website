# ShopEasy - E-Commerce Website 🛍️

## About the Project
ShopEasy is a simple, responsive front-end e-commerce website built using HTML, CSS, and JavaScript. Users can browse products, search for items, add products to their shopping cart, update quantities, and view their order summary through a demo checkout.

## Features
- Display products with images and prices
- Search products by name
- Add products to the shopping cart
- Increase or decrease product quantities
- Remove products from the cart
- Automatically calculate the total price
- Display the total number of items in the cart
- Save cart data using Local Storage
- Responsive layout for mobile devices
- Demo checkout with an order summary and thank-you message

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Browse products, search for items, and add them to your cart.
5. Click the Cart button to manage items and try the demo checkout.

## How It Works
- **Product Search:** Filters products based on the entered name.
- **Shopping Cart:** Allows users to add, remove, and update product quantities.
- **Price Calculation:** Automatically updates the total based on the selected quantities.
- **Local Storage:** Preserves cart contents after refreshing the page.
- **Checkout:** Displays an order summary and clears the cart after the demo is completed.

## Future Improvements
- Add product categories and filters.
- Add a product details page.
- Integrate a backend for order management.

## Limitations
This is a front-end demonstration project. Checkout does not process real payments or create actual orders. Cart data is stored locally in the user's browser.
